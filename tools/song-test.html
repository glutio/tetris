gotetris song tester

Paste a song in the Music.songs format and press Play. It uses the same synth as the game. An optional roots: { X: 40 } adds chords that aren't built in.

Format
  • melody: notes separated by spaces. C D E F G A B = octave from C5, lower case = octave up, trailing , = octave down (A,). ^F sharp, _B flat (no key signature). Length in eighths after the note: E=1/8, E2=1/4, E4=1/2, E1.5 dotted, E.5=1/16. z2 = rest.
  • chords: name:eighths, played as root/octave bass. Must add up to the melody length; total should be a multiple of 4 eighths.
